# ZCMS0070T (Table Type)

테이블 타입은 소스 형태가 없다. SE11 → Data type → Table type으로 아래 값을 입력한다.

| 항목 | 값 |
| --- | --- |
| Table type | `ZCMS0070T` |
| Short description | `[CM] CBO Authorization Check Request List` |
| Line type | `ZCMS0070` (Line Type 라디오 선택 후 입력) |
| Access | Standard Table |
| Key definition | Standard Key |
| Key category | Non-Unique |
| Initial line number | 0 |
| Package | `ZCM00` |

`ZCMS0070` 구조를 먼저 활성화한 뒤 생성한다.
